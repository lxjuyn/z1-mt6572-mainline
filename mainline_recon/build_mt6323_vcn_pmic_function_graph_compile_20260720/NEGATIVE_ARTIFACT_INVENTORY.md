# Negative artifact inventory

This package must not contain any compile or deployment artifact. The validator
records the inventory after `olddefconfig` in `negative-artifact-inventory.txt`.

Forbidden classes checked under this package:

- `vmlinux`, `System.map`, `*.o`, `*.a`, `*.ko`, `*.mod*`, `modules.*`
- `zImage`, `Image`, `Image.gz`, `*.dtb`, `*.dtbo`, `zImage_appdtb*`
- `*.img`, `*.gz`, `*.cpio*`, `boot*`, `flash*`, `fastboot*`, `mkbootimg*`
- linker/map/symbol outputs and hardware/flash launcher scripts

Expected result: every forbidden class is empty. Kconfig metadata generated by
`olddefconfig` inside `kbuild/` is allowed; no C compilation output is allowed.
